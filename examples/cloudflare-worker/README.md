# ⚡ smsGAClient Cloudflare Worker — وب‌هوک و شبیه‌ساز سرورلس

این نمونه کد یک **سرور رایگان، ابری و بدون نیاز به هاست/VPS (Serverless)** روی بستر **کلودفلر (Cloudflare Workers)** است که توسعه‌دهندگان و فروشندگان می‌توانند در کمتر از **۲ دقیقه** آن را بالا بیاورند و آدرس آن را در اپلیکیشن **smsGAClient** وارد کنند تا تست‌های پرداخت کارت‌به‌کارت را شبیه‌سازی و بررسی کنند.

---

## 🌟 امکانات این ورکر:
- 🔒 **اعتبارسنجی کامل امنیتی**: بررسی توکن Bearer، پنجره زمانی (ضد Replay Attack) و امضای رمزنگاری `HMAC-SHA256` با Web Crypto API.
- 🗄️ **پایگاه داده ابری KV (Cloudflare KV)**: ذخیره خودکار تراکنش‌ها، عدم تکرار (Idempotency) و نگهداری لاگ‌ها تا ۱۴ روز.
- 📊 **داشبورد زنده و دارک‌مود**: باز کردن آدرس دامنه در مرورگر و مشاهده لحظه‌ای لیست پیامک‌های واریزی دریافت شده از گوشی با فونت وزیرمتن.
- 🤖 **ارسال فوری به ربات تلگرام (اختیاری)**: ارسال اعلان شکیل به تلگرام فروشنده به محض دریافت واریزی.
- 💸 **۱۰۰٪ رایگان**: با ۱۰۰٬۰۰۰ درخواست در روز در پلن رایگان Cloudflare بدون پرداخت هیچ هزینه‌ای!

---

## 🚀 روش راه‌اندازی ۱: پیست کردن مستقیم در پنل کلودفلر (سریع‌ترین روش - بدون نیاز به کدنویسی)

1. وارد اکانت رایگان خود در [Cloudflare Dashboard](https://dash.cloudflare.com) شوید.
2. از منوی کناری به بخش **Compute (Workers & Pages)** بروید.
3. روی **Create Application** و سپس **Create Worker** کلیک کرده و یک نام انتخاب کنید (مثلاً `smsga-webhook`).
4. روی **Deploy** کلیک کنید.
5. وارد صفحه ورکر شوید و روی **Edit Code** کلیک کنید.
6. محتوای فایل [`src/index.js`](src/index.js) موجود در همین پوشه را به طور کامل کپی کرده و جایگزین کدهای قبلی کنید و دکمه **Deploy** را بزنید.
7. آدرس وب‌هوک شما آماده است!
   ```text
   https://smsga-webhook.<subdomain>.workers.dev/webhook
   ```

---

## 💻 روش راه‌اندازی ۲: با دستور Wrangler CLI

اگر با خط فرمان کار می‌کنید:

```bash
cd examples/cloudflare-worker

# ورود به حساب کلودفلر
npx wrangler login

# (اختیاری) ایجاد دیتابیس KV برای ذخیره تراکنش‌ها
npx wrangler kv namespace create SMSGA_KV

# پابلیش روی کلودفلر
npx wrangler deploy
```

## ⚙️ متغیرهای محیطی (Environment Variables)

در فایل `wrangler.toml` یا در تب **Settings -> Variables** در داشبورد کلودفلر می‌توانید متغیرهای زیر را تنظیم کنید:

| نام متغیر | مقدار پیش‌فرض | توضیحات |
| :--- | :--- | :--- |
| `API_TOKEN` | `smsga_live_token_123456` | توکن احراز هویت که در تنظیمات اپلیکیشن وارد می‌کنید |
| `HMAC_SECRET` | `smsga_live_secret_abcdef` | کلید مخفی امضای HMAC جهت اعتبارسنجی پکت‌ها |
| `TELEGRAM_BOT_TOKEN` | *(اختیاری)* | توکن ربات تلگرام برای ارسال اعلان لحظه‌ای واریز |
| `TELEGRAM_CHAT_ID` | *(اختیاری)* | شناسه چت یا کانال تلگرام برای دریافت اعلان‌ها |

## 📱 نحوه اتصال و تست در اپلیکیشن smsGAClient

1. وارد تب **تنظیمات (Settings)** در اپلیکیشن گوشی شوید.
2. فیلد **آدرس وب‌هوک (Webhook URL)** را روی آدرس ورکر خود قرار دهید:
   ```text
   https://smsga-webhook.<your-subdomain>.workers.dev/webhook
   ```
3. فیلد **توکن دسترسی (API Token)** را برابر با مقدار `API_TOKEN` خود بگذارید.
4. دکمه **«ارسال پیامک آزمایشی»** را لمس کنید!
5. نتیجه `200 OK: Test SMS verified successfully` را مشاهده خواهید کرد و در داشبورد وب این ورکر نیز پیامک ثبت می‌شود.
