# 🏦 بانک‌های تحت پوشش و راهنمای مشارکت (Bank Patterns Contribution Guide)

سامانه **smsGAClient** بر پایه الگوهای ماژولار و قابل توسعه طراحی شده است. هر بانک ایرانی دارای یک فایل مستقل JSON در این پوشه است.
اگر پیامک بانکی جدیدی دارید، فرمت پیامک بانک شما تغییر کرده است، یا قصد اضافه کردن یک بانک جدید را دارید، می‌توانید به سادگی یک **Pull Request (PR)** ارسال کنید!

---

## 📂 ساختار فایل‌های هر بانک (File Structure)

هر بانک در یک فایل اختصاصی با نام شناسه انگلیسی آن (مثلاً `blu.json` یا `mellat.json`) ذخیره می‌شود:

```json
{
  "id": "blu",
  "name_fa": "بلوبانک",
  "name_en": "Blu Bank",
  "card_prefixes": ["621986"],
  "senders": ["BLUBANK", "blubank", "+982000021"],
  "detect_regex": "(بلو|blu|سامان.*بلو)",
  "deposit_regex": "\\+(?<amount>\\d+)\\s*ریال",
  "withdraw_regex": "-(?<amount>\\d+)\\s*ریال",
  "card_regex": "(?<card>\\*{0,4}\\d{4})",
  "balance_regex": "موجودی[:\\s]*(?<balance>\\d+)",
  "sample_sms": [
    {
      "type": "DEPOSIT",
      "raw": "+۴٬۵۰۰٬۲۸۰ ریال — بلو کارت ****۱۲۳۴ موجودی: ۱۲۵٬۰۰۰٬۰۰۰ ریال",
      "expected_amount_rial": 4500280,
      "expected_card_last4": "1234",
      "expected_balance_rial": 125000000
    }
  ]
}
```

## 📝 فیلدهای فایل پیکربندی (Field Specification)

| نام فیلد | نوع | توضیحات |
| :--- | :---: | :--- |
| `id` | رشته (String) | شناسه منحصر‌به‌فرد انگلیسی بانک (کوچک، بدون فاصله) |
| `name_fa` | رشته (String) | نام رسمی بانک به زبان فارسی |
| `name_en` | رشته (String) | نام رسمی بانک به زبان انگلیسی |
| `card_prefixes` | آرایه (Array) | ۶ رقم ابتدایی شماره کارت‌های این بانک (BIN Code) |
| `senders` | آرایه (Array) | سرشماره‌ها یا نام‌های فرستنده پیامک (Sender Address / Mask) |
| `detect_regex` | رجکس (Regex) | الگوی تشخیص نام یا نماد بانک از متن پیامک در صورت نبود فرستنده معتبر |
| `deposit_regex` | رجکس (Regex) | الگوی استخراج تراکنش **واریز** با گروه نام‌گذاری شده `(?<amount>\d+)` |
| `withdraw_regex` | رجکس (Regex) | الگوی استخراج تراکنش **برداشت** با گروه نام‌گذاری شده `(?<amount>\d+)` |
| `card_regex` | رجکس (Regex) | الگوی استخراج ۴ رقم آخر کارت با گروه نام‌گذاری شده `(?<card>\d{4})` |
| `balance_regex` | رجکس (Regex) | الگوی استخراج مانده موجودی با گروه نام‌گذاری شده `(?<balance>\d+)` |
| `sample_sms` | آرایه (Array) | نمونه پیامک‌های واقعی بانک همراه با خروجی‌های مورد انتظار جهت تست خودکار |

## 💡 قوانین رجکس (Regex Rules)

1. **نرمال‌سازی پیش‌فرض**: موتور اپلیکیشن پیش از اعمال رجکس، تمام اعداد فارسی و عربی (۰۱۲۳۴۵۶۷۸۹) را به ارقام انگلیسی تبدیل کرده و جداکننده‌های هزارگان (کاما، ویرگول، نیم‌فاصله) را حذف می‌کند. بنابراین رجکس‌های شما فقط با اعداد پیوسته لاتین (`\d+`) کار خواهند کرد.
2. **گروه‌های نام‌گذاری‌شده الزامی**:
   - مبلغ تراکنش: `(?<amount>\d+)`
   - ۴ رقم آخر کارت: `(?<card>\d{4})`
   - مانده موجودی: `(?<balance>\d+)`
3. **Escaping**: کاراکترهای بک‌اسلش در رشته‌های JSON باید به صورت `\\` دوبل نوشته شوند (مانند `\\d+`).

## 🚀 نحوه ثبت درخواست مشارکت (How to Submit a PR)

1. از این مخزن یک **Fork** بگیرید:
   ```bash
   git checkout -b feature/add-new-bank-pattern
   ```
2. فایل بانک مورد نظر را در مسیر `banks/<bank_id>.json` اضافه یا ویرایش کنید.
3. حداقل ۱ نمونه پیامک واقعی (بدون اطلاعات حساس) به بخش `sample_sms` اضافه کنید.
4. تغییرات را کامیت کرده و یک **Pull Request** ارسال نمایید.
5. پس از بازبینی و اجرای تست‌های خودکار CI/CD، الگوی جدید شما با شماره نسخه بالاتر در آپدیت‌های برنامه ادغام خواهد شد!
